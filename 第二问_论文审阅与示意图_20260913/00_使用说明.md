# 第二问论文审阅与两套示意图

## 阅读顺序

1. `审阅意见.md`：逐项解释值得修改的数学问题，以及可复核的边界反例。
2. `建议替换正文.tex`：可替换当前段落的 LaTeX 片段，保留了两张图的标签和 `q2/` 图片路径。若后文已有目标函数，可避免重复插入对应段落。
3. `rendered/`：LaTeX/TikZ 精确排版渲染版，每张图有 TEX、PDF、300 dpi PNG。
4. `python/`：Matplotlib 版，每张图有 PDF、SVG、300 dpi PNG。

`q2/` 中放置了推荐用于论文的 TikZ 渲染版 PNG/PDF。将整个 q2 文件夹复制到论文项目，即可使用原来的 `\includegraphics{q2/fig_prior_sector.png}` 和 `\includegraphics{q2/fig_geometry_intersection.png}`。如果选 Python 版，将 python/ 中同名 PNG 或 PDF 替换进去。

推荐在论文中将扩展名改为 `.pdf`，使用矢量图。图片已经嵌入字体，直接引用 PDF/PNG 不要求论文环境安装本机字体。

## 图的含义

- 图 1：面积均匀先验与极坐标微元；为可读性扩大主图角度及内半径，实际参数说明保留在正文图注。微元矩形是微分意义的一阶示意。
- 图 2：左侧为按实际比例绘制的双站布设；右上为距离边界不裁剪时的四边形特例；右下为 1500 米圆弧裁剪的数值反例。子图各自采用等比例坐标，避免把误差楔形画成平行条带。

两套图共享同一几何说明，但由 TikZ/XeTeX 与 Matplotlib 分别排版和生成。所谓渲染版在此指 LaTeX/TikZ 渲染，不是 AI 位图生成。

## 复现图形

使用 Python 3.12，安装 numpy、matplotlib、shapely、numba；当前验证环境与第二问研究环境相同。

```text
python audit_geometry.py
python make_figures.py
```

第一步计算普通及边界例子的精确几何，并用独立多边形几何库核验；第二步输出 Python 版和 TikZ 源码。示例坐标保存在 geometry_examples.json，参考核验结果保存在 independent_geometry_check.json。support/geometry.py 是此前已验证几何程序的原样副本。

渲染 TEX 可使用 XeLaTeX 或 Tectonic：

```text
tectonic --outdir rendered rendered/fig_prior_sector.tex
tectonic --outdir rendered rendered/fig_geometry_intersection.tex
```

本机使用 Tectonic 0.17.0。TikZ 源码指定 Times New Roman 和 SimSun（宋体）；在没有这两种字体的环境中重编译时，可分别改为 TeX Gyre Termes 和 FandolSong-Regular。直接插入已生成的 PDF/PNG 不受此限制。
