# 运行与文件说明

## 环境与安装

已验证环境：Windows 11、Python 3.12.14（64 位）。依赖版本固定在 requirements.txt。建议在本文件夹建立独立环境；安装依赖需要联网。无需重新安装依赖即可阅读所有已生成的结果。

在此文件夹打开 PowerShell，使用已经安装的 Python 3.12：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

如果没有 Windows Python 启动器 py，可用 Python 3.12 可执行文件的实际路径替换 `py -3.12`。

## 三种运行方式

```powershell
# 仅检查交接文件是否完整，不需要第三方依赖。
.\.venv\Scripts\python.exe run_reproduce.py --verify

# 快速重做 360 组独立几何核验。
.\.venv\Scripts\python.exe run_reproduce.py --quick

# 全部重算：搜索、细化、几何核验、统计、舍入、报告和图表。
.\.venv\Scripts\python.exe run_reproduce.py --all
```

统一入口可以从任何工作目录启动。它把代码复制到 `_复现输出/时间戳/` 后运行，随包交付的 results 不会被覆盖。全量复现时间随机器和首次编译开销变化，通常为几分钟至十几分钟；当前机器实测数据不应视作其他机器的耗时保证。图表默认使用微软雅黑字体；在没有该字体的系统上，请配置可用中文字体。

## 程序分工

| 文件 | 职责 |
| --- | --- |
| geometry.py | 真实直线、圆弧交集面积、直径、最小包围圆、近距离分支与观测模拟 |
| benchmark.py | 角度支持区间、平均目标自适应积分及计时 |
| objectives.py | 安全域参数化、两种目标、滑动最坏误差和加权统计 |
| solve.py | 在指定安全域中初步搜索和边界细化 |
| refine.py | 在初筛确定的 1000 米边界上用自适应积分细化 |
| validate_geometry.py | 使用独立几何库对照 360 个案例 |
| statistics_run.py | 七方案完整统计、20 万组共同场景模拟和舍入包含性核验 |
| final_checks.py | 3240 个安全域点补充扫描、多级积分收敛和舍入后局部再优化 |
| make_report.py | 从统计文件生成中文报告、三张图和角度曲线数据 |
| run_reproduce.py | 完整性校验与统一复现入口 |

## 结果文件与单位

| 文件 | 内容 |
| --- | --- |
| results/policy_comparison.csv | 7 个方案的坐标、角度、距离、普通及逐目标最坏的统计量 |
| results/policy_statistics.json | 完整积分统计，额外含区域面积、最小包围圆半径和覆盖概率 |
| results/optima_initial.json、optima_refined.json | 初筛、细化点及误差估计 |
| results/optimization_history.csv | 搜索过程记录 |
| results/paired_monte_carlo.json | 20 万组模拟汇总、成对差值和标准误 |
| results/paired_200000_scenes.npz | 20 万组目标坐标、误差、各方案逐样本直径和包围圆半径 |
| results/*_angular_distribution.npz | 各方案角度节点、读数密度、直径、真实方位密度、逐目标最坏直径 |
| results/rounding_validation.json | 0.01° 舍入后是否包含真目标的核验 |
| results/rounded_reoptimization.json | 舍入模型在连续最优点附近的局部再优化 |
| results/geometry_validation.json | 独立几何参考误差 |
| results/quadrature_convergence.json、search_coverage.json | 网格收敛、安全域扫描及径向检查 |
| results/figures/ | 三张 PNG 图 |
| results/angle_profile.csv | 1000 米边界上角度与目标值关系 |
| results/chart_notes.json | 图表的数据、单位与可视化说明 |

长度字段 `_m` 单位为米，面积字段 `_m2` 单位为平方米，角度 `_deg` 单位为度。NPZ 中的角度和误差为弧度，密度按弧度定义。JSON 概率为 0～1，报告中转为百分比。`ordinary_observation_statistics` 表示目标与误差都随机；`per_source_worst_statistics` 表示逐目标先取最坏误差。主结果使用自适应积分，密集网格统计的末位可能略有不同。

## 读取原始模拟数据

```python
from pathlib import Path
import numpy as np

base = Path('results')  # 在交接包目录运行；其他位置请指定实际路径。
with np.load(base / 'paired_200000_scenes.npz') as data:
    print(data.files)
    print(data['source_x'].shape)  # (200000,)
    print(data['mean_optimum_diameter'].mean())
```

随机种子固定在程序中。七种方案使用共同目标、共同标准化误差进行成对评价，以降低差值估计噪声；它不宣称现实中不同位置误差必然相同。
