# 2026-09-12 第一问修改说明

## 版本定位

本次按“补齐第二种方法的特殊情况，并完成第一问”的要求新增独立交接目录，保留原有分享包和改进版。主程序仍叫 `q1_localization.py`，接口尽量延续旧版，但内部半平面求交改成上下包络队列。

第二种方法的核心是排序后单调维护有效边界。经典写法把闭合多边形边界放入一个队列；它在空集、无界、平行和退化情况同时出现时，收尾逻辑容易出错。本版分别维护上、下边界，再合并它们的有效横坐标区间，能够直接区分这些状态。

第三种方法是把每条边界参数化后，与全部其他半平面逐一求参数区间；每条边界都重新扫描全部约束，通常为 $O(m^2)$。新版合并的是两条已构造好的包络，各自指针只前移，没有重复逐边界扫描，因此两者不能因为都出现“区间”二字就混为一谈。

## 特殊情况补齐表

| 特殊情况 | 风险 | 本版做法与检查 |
|---|---|---|
| 方向跨0°/360° | 角度排序首尾被分开 | 由正余弦生成有向半平面，分组后按斜率排序，不用跨周角度区间比较 |
| 同向平行 | 除以0；较弱约束覆盖较强约束 | 同一组斜率相同只留最大截距；两组都统一用最大包络 |
| 反向平行 | 把条带或直线误判为空 | 相反约束分属上/下界或左/右界；分别检查相容、相等和矛盾 |
| 完全重复与冗余 | 重复极点、冗余计算 | 同向筛选、队尾弹出；最后凸包去重、去共线点 |
| 多线交于同点 | 队列切换区间长度0 | 新切换点不大于旧起点时弹出无有效区间的中间边界 |
| 空集 | 平行矛盾未查；伪造有限结果 | 检查竖直界及 $L(x)\le U(x)$ 的可行性，返回 `empty` |
| 无界区域 | 有顶点就误认为有界；大包围盒产生假顶点 | 检查竖直方向是否封闭和可行横坐标是否有限；返回 `unbounded` |
| 单点 | “不足3个顶点”被拒绝 | 合法输出一个极点，直径0、半径0 |
| 竖直/斜向线段 | 上下界重合被当成异常 | 合法输出两个端点，直接计算距离 |
| 近平行、薄区域 | 宽角度阈值误删真实边界 | 除四轴残差阈值外，不合并斜率不同的边界；覆盖1e-11方向差及1e-6米薄区测试 |
| 大平移 | 大坐标差分抵消 | 将半平面平移至首条边界点附近再求交，最后还原；测试200万米平移 |
| 微小多边形卡壳 | 固定面积容差提前停止 | 按边长×步长缩放相对容差，并检查平行支撑的相邻对踵点 |
| 无效与极端数值 | NaN/Inf传播；静默错误 | 输入有限性、非零方向检查；交点溢出及包络复核失败显式报错 |
| 零法向约束 | 无法单位化 | 一般系数入口把 $0\ge c$ 单独分成恒真或恒假 |

## 保住复杂度的实现选择

设输入约束数为m，最终极点数为k。

- 两组函数排序：$O(m\log m)$。
- 每条边界入队一次、最多出队一次：$O(m)$。
- 合并两组折点和解一次不等式：$O(m)$。
- 候选端点凸包：$O(m\log m)$。
- 对极点用二分查询包络复核：$O(k\log m)$，没有对每个极点重扫m条约束。
- 旋转卡壳和覆盖检测：$O(k)$。

总计 $O(m\log m)$ 时间、$O(m)$ 空间。主程序既不导入 `reference/`，也没有在特殊输入时转为逐边界区间法或人工包围盒的分支。独立核验里的两两交点枚举只属于离线测试，未混入运行复杂度。

## 对第一问结论的补强

旧版示例270°可以覆盖，不能据此回答“总是可以”。本包另给269°的可行测向反例，并证明：半径为D/2且含最远点对A、B的圆，其圆心只能在A、B中点。该圆不覆盖时，换圆心也无济于事。

覆盖仅需检查极点，因为圆盘和定位区域都具有凸性。对于后续20米光学清除，不能只用 $D\le40$ 作为充分条件；应另行检查存在覆盖圆或最小包围圆半径。

## 验证与材料

52项测试方法通过；保留旧21项回归，新增31项特殊情况检查。旧回归方法内部还包含100组卡壳与300组测向枚举对照。另用1500组独立线性规划/交点枚举核验。计时结果在 `results/benchmark.csv`，图件和报告从这些记录生成，不手写耗时。

## 尚需保留的限制

这是双精度实现，精确实数模型的正确性证明与浮点实现的适用范围应分开表达。默认位置容差1e-10米，单位方向分量1e-14以内的轴向残差归零；极近轴的真实小分量可能受影响。容差尺度内的薄区可能被合并成线段/单点；计算极度病态时应审查原始约束，必要时改用高精度实现，不能无条件认定所有尺度准确。

报告里的角度区域不包含圆弧裁切。仅靠半平面交无法精确处理额外圆形约束。也没有替换第二、三问代码或作官方模拟器测试。
