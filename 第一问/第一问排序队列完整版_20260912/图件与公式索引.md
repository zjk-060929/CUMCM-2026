# 图件与公式素材索引

所有图件由 `generate_figures.py` 用本包求解结果、明确给定的示意约束或实际计时结果绘制，未使用AI生成位图。图件PNG为220 dpi，公式PNG为250 dpi；同时提供SVG，适合缩放排版。图片中的长度单位为米。

## 九幅图

下表文件名均省略 `.png` / `.svg` 后缀。图件文件编号按素材组织，报告图号按正文出现顺序。

| 报告图号 | figures/文件名 | 用途与数据来源 |
|---|---|---|
| 图1 | `fig8_algorithm_flow` | 本版完整计算流程 |
| 图2 | `fig1_bearing_intersection` | `counterexample_input.json` 两个测向角形与交集放大 |

## 十个公式

每个公式均有 `formulas/编号.png` 与 `.svg`。全部LaTeX源码另存为 `formulas/formulas.tex` 和 `formulas/formulas.json`。`公式推导补充.md`提供比单独公式更完整的定义与证明。

| 编号 | 内容 |
|---|---|
| `eq01_angle` | 示向度误差半角 |
| `eq02_halfplane` | 有向半平面与定位区域 |
| `eq03_envelopes` | 下包络与上包络 |
| `eq04_switch` | 排序队列的接管横坐标 |
| `eq05_feasibility` | 横坐标可行区间 |
| `eq06_vertices` | 有界区域等于极点凸包 |
| `eq07_diameter` | 顶点直径公式，包含单点情况 |
| `eq08_circle` | 直径圆圆心、半径与覆盖判断 |
| `eq09_complexity` | 时间、空间复杂度 |
| `eq10_triangle` | 等边三角形最小包围圆反例 |

公式中的max/min默认对应非空函数组；缺少上下约束的无界分类按正文说明处理。排版时不要单独引用公式而省略其适用条件。

## 修改图件

修改 `generate_figures.py` 后执行 `python generate_figures.py`。若改动了输入算例，还应检查 `example_results.json` 与图中文字一致；报告中的269°反例段落是固定的本题反例，改动输入意味着也需要同步修改 `report_content.py` 的算例说明。

SVG字体已转路径，适合直接放入排版软件。需要编辑具体文字时，更推荐改图件脚本后重新生成；TeX和JSON中的公式源码可以直接复制到支持LaTeX的公式编辑器。
