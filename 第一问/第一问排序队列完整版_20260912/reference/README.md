# 旧算法参考副本

本目录用于可复现计时，不参与新求解器默认运行。

| 文件 | 本次交付时的来源（相对CUMCM-2026仓库） |
|---|---|
| `interval_reference.py` | `第一问/第一问改进版/第一问/q1_localization.py` |
| `legacy_deque.py` | `第一问/B题第一问_队友分享包_20260911/q1_localization.py` |

两份文件原样复制并保留原有注释。`benchmark.py`以独立模块名导入，避免与新版 `q1_localization` 混淆。比较限于三份实现都应处理的普通有界输入，不能推断旧版已经支持新包列出的全部特殊情况。

`interval_reference.py`采用逐边界参数区间交；`legacy_deque.py`采用单个闭合边界队列，含最终逐极点逐约束复核。因此旧队列代码在所有边界有效时也可能表现出二次增长。文件中的历史复杂度表述属于旧版本内容，应以新版报告对实际执行路径的分析为准。
