# 使用与复核

## 离线复核

在 `01_最终代码` 中执行：

```powershell
& "D:\Anaconda\python.exe" -m unittest discover -s tests -v
```

预期结果为50项测试全部通过。

只检查配置和七点布局、不连接模拟器：

```powershell
& "D:\Anaconda\python.exe" run_practice.py --case-code "AB12-CD34-EF56-GH78" --dry-run
```

## Jammer运行

1. 启动 Jammer 并打开正确的问题3测试页面；
2. 等待数据准备和倒计时结束；
3. 确认页面显示“等待机器狗进入”；
4. 记录页面显示的完整案例编码；
5. 在 `01_最终代码` 中执行：

```powershell
& "D:\Anaconda\python.exe" run_practice.py --case-code "页面显示的实际案例编码"
```

6. 正常结束后核对终端中的发现数、清除数、虚拟时间和 `/exit` 状态；
7. 保存 `logs` 中的 JSONL、摘要 JSON，以及 Jammer 导出的 `.jlog`。

无门禁入口会立即请求 `/enter`，同一局只能启动一个客户端。
