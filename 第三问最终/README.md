- 最终策略：`p3_joint_orienteering_spatial_exact2_v6`

- 覆盖布局：七点极小极大布局
- 队内运行配置：队号 `202617241078`、本机端口 `2026`
- 入口形式：无门禁；提供案例编码后直接调用 `/enter`

- `01_最终代码`：截图所示的最终源码、配置与50项离线测试；
- `02_实测结果`：7次模拟器运行摘要及正式测试第1次的完整证据；
- `03_说明文档`：算法、实测结论、使用方法和提交前检查。

## 运行

在 Jammer 页面生成实际案例编码并显示“等待机器狗进入”后，在
`01_最终代码` 中运行：

```powershell
& "D:\Anaconda\python.exe" run_practice.py --case-code "实际案例编码"
```

例如：

```powershell
& "D:\Anaconda\python.exe" run_practice.py --case-code "AB12-CD34-EF56-GH78"
```

该入口没有二次确认，执行后立即连接 `127.0.0.1:2026`。程序不会启动或点击
Jammer 界面，运行前必须由操作者确认页面和题号正确。
