# 第四问：三个对话的方法整合

该目录以自主启发式分支冻结的逐动作规划为基础，吸收主线迭代 (2) 的边界交会补救及主线迭代 (3) 的巡检放宽条件。历史分支、原数据和入口保持可复现。它是新的综合候选，不代表之前几个分支已经自动合并。

## 已实现的机制

1. **1024边保守定位。** 源域圆与正测角的1500米接收上界圆均使用1024边外切多边形。1800米圆最大外扩约0.00847米，1500米圆约0.00706米。每次实际测角保留完整±1.005°；不平均掉相关误差。发现证书仍对较大的原128边源域验证，足以覆盖1024边源域。
2. **逐动作重规划。** 每次只执行一个真实测量或清除请求；其后更新区域、负观测和各站剩余频道，再重新搜索。清除失败、near结果和光学覆盖也分别进入下一次规划。保留插入法、最近邻、上一轮路线、交换、移动、区段反转及块移动；标准搜索3层/宽4，扩大搜索5层/宽12，并增加局部搜索预算。
3. **按实际候选动作位置计价。** 任务入口采用真正将去的测量点、试清除点或安全清除点；测量后的预计出口与后续任务连接也纳入路线。执行采用规划中选定的动作，不再用目标中心排序后临时换成另一个点。未来几何和失败恢复仍是有限假设下的预测，尚非完整反馈树的精确期望。
4. **巡检参考与有条件放宽。** 累计实际站点到达前缀计入预算。候选必须真的超过当前上限、具有正的已知目标服务收益，并在扣除最后发现风险后仍预计至少省20秒，才允许例外。最后发现风险使用共同的离散隐藏源假设及总数为16的权重，提前发现其他位置不能抵消最后目标拖晚。部分扫描中断导致旧预算不可行时，显式记录预算可行性修复，不能将其当作已证明的提速；该约束仍依赖预测模型。
5. **边界圆弧与外侧交会。** 只在内部站观测稀疏、存在外侧正观测等证据支持时，提出圆周交弧试清除。失败后在外法向60米、切向±90米处构造两次有限补测，并按真实反馈决定下一动作。每源最多一个过程；不把源强制限制在圆周。测量、失败清除和往返均真实计费。
6. **付费补测换路程。** 在当前位置和下一路段的25%、50%、75%及目标投影位置比较补测。估计相对下一终点观测的增量几何收益，收到/收不到共用同一发射半径与朝向假设。每场可选补测最多40次；连续3次没有显著改善时暂停；样本耗尽或已进入光学覆盖时不借其高风险反复推荐同目标补测。已知源有效测角至少相隔50米，但不声称50米外误差独立。
7. **连续光学兜底。** 维持完整连续区域的覆盖点和风险估计。规划比较不会消耗覆盖点，也不会仅因为评估过兜底就暂停机会测量；实际尝试后才移除相应点。兜底保持有限，不能保证任意场景都不触发或都能在400秒内完成。

## 验证口径

所有对照使用同一目标布局、同一四波平滑空间误差场、相同费用及同一几何真值审计。逐场检查清除完成、真实源位置包含、有效测角间距、未知频道发现证书及完整时间账。其他对话使用过不同误差场，原报告的448、453等不能直接拼接排名。

本轮预设完整任务仿真上限550次，开发阶段先比较方案，再冻结参数，最后使用新布局作同场景验证。同一布局的多个误差尺度按同一布局聚合计算不确定性。具体结果见本目录最终报告与results中的清单、原始记录。

运行入口位于上一级：`run_integrated_q4.py`。默认使用本轮冻结候选；入口会核对源码哈希。该入口是离线模拟，不是官方通信客户端。
