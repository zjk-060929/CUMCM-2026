# 运行、复现与材料清单

## 1. 环境与离线范围

Python 3.10及以上。算法、测试、核对与统计表只使用标准库。绘图脚本另需Matplotlib：`python -m pip install -r requirements-figures.txt`。已附PNG和SVG，正常读报告无需安装绘图库。

所有公开的包根入口都使用本包中的代码和相对位置，可从任意工作目录用绝对路径启动。输出写入新的 `runs/` 子目录或指定的新目录。原始506次研究记录保留在 `code/integrated_q4_20260913/results/`。

**本包默认完全离线，不会连接官方模拟器，也不会消耗正式测试次数。** 冻结算法通过统一的客户端请求抽象工作，但最终整合版的官方HTTP联调和三次正式测试不在本包已完成事项中。

## 2. 完整性与针对性测试

在解压目录执行：

```text
python -B check_package.py
python -B run_checks.py
```

第一条核对交付文件SHA256及5个对照方案的冻结源码。第二条运行14项几何、状态更新与预算条件测试。部分测试覆盖继承的底层组件，不意味着历史入口中的每一种选项都启用于最终策略。测试记录写入 `runs/tests_日期时间/tests.txt`。

`MANIFEST_SHA256.json` 自身不参与自身哈希；`runs/` 是新运行区，不属于冻结材料。修改冻结代码后核对失败是预期行为，不能删掉核对来继续声称正在复现同一版本。

## 3. 单场运行

```text
python -B run_demo.py --seed 42 --scale 300
```

原研究相同案例整合版结果为：10个源全部清除，总模拟时间5677.158914秒，567.715891秒/源，路程20415.794571米，检测259次，失败清除1次，最后光学覆盖0次。它是固定功能样例，不代表普通组均值。

可选场景为 `mixed`、`edge_outward`、`rotated_cluster`、`minimum_range`、`edge_inset`。例如：

```text
python -B run_demo.py --seed 292002 --scale 300 --mode edge_outward
python -B run_demo.py --seed 42 --scale 300 --variant expanded
```

`--variant integrated` 是默认；`expanded` 扩大搜索，`free` 取消巡检路程保护，`no_sensing` 关闭额外机会补测。这些是开发比较选项，不应混成同一最终成绩。

## 4. 不重新仿真，核对论文统计和重画图

```text
python -B reproduce_tables.py
python -B make_figures.py
```

前者从逐场原始记录重建5张CSV，检查345场新检验中的源数、时间账、共同布局、共同误差样本及报告均值。它不会产生新的完整任务仿真。P90沿用原实验定义：对排序后K个数取零基索引 `floor(0.9*(K-1))`，不作线性插值。

配对区间按14个独立普通布局聚合3种尺度的差值，以固定种子612031作5000次布局自助重采样；区间采用原实现的百分位索引。该区间是有限样本估计，不是严格概率保证。

绘图使用这些表和原始数据，输出PNG及SVG；SVG文字转成路径，跨电脑引用不依赖中文字体。重新绘图需要本机具有可用中文字体；Windows默认优先微软雅黑。

## 5. 有限次重新仿真

最小的同场跨版本核对：

```text
python -B rerun_benchmarks.py --variants fifth eighth boundary reliable integrated --case-limit 1
```

这会运行新检验清单中的第一场、共5次完整任务，并与已归档结果比较总时间、路程、检测、换频、清除及站数。默认不加参数只运行整合版1场。

完整重跑69场整合版：

```text
python -B rerun_benchmarks.py --full --variants integrated
```

完整重跑本轮5版×69场新检验：

```text
python -B rerun_benchmarks.py --full --variants fifth eighth boundary reliable integrated
```

两条命令分别产生69、345次完整任务，运行前会显示次数。新目录内保留结果、日志、任务列表和逐场比对；不会覆盖归档。`--stage development` 可选择开发清单，配合 `--variants integrated expanded free no_sensing` 复算消融。

重新运行的程序耗时随CPU、Python版本及系统负载变化；算法费用和动作计数应一致。浮点差异可能影响极近的候选代价并引起后续分支变化，脚本发现不一致时会明确报出，不能静默替换旧成绩。

原始配置中的 `completed_whole_runs=160` 表示冻结时已完成的6次检查＋154次开发，不是研究最终总数；最后总账为 `results/final_audit.json` 的506。包装验收次数另列在 `validation/交付验收.json`，不并入研究统计。
