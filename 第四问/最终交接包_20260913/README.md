## 写论文时保持这些区别

1. 这是带连续几何保证条件的在线启发式算法，不是整个搜索、定位与清除问题的全局最优解。
2. 21站布局有连续方向覆盖的充分条件核验，没有“21站最少”或“巡检路径全局最短”的证明。
3. 最终定位保留测向夹角，圆用1024边外切多边形近似；没有把夹角统一替换成长条，也不是精确求所有圆弧交集。
4. 误差与位置相关，完整误差界始终保留；50米间距只是算法筛选门槛，不能写成误差从此独立。
5. 506次是算法研究阶段的完整离线仿真总数；包装验收另记，既不用于调参，也不并入论文比较样本。
6. 本包没有官方三次正式测试的案例编码或加密日志。正式测试表保持待填写，不能把自建案例种子当成官方案例编码。

历史代码按原有相对结构保留，是为了复现对照与核对哈希。日常使用上面的包根入口；不要从历史文件名推断默认方案。
